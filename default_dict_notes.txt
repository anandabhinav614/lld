Think of it as a regular dict that has a factory function to automatically create a default value when you access a missing key.

Regular dict behavior
    d = {}
    d["key1"] += 1  # ❌ KeyError: 'key1'

defaultdict behavior
    from collections import defaultdict

    d = defaultdict(int)
    d["key1"] += 1  # ✅ Works! "key1" gets auto-created with int() = 0, then += 1
    print(d)        # {'key1': 1}

The Three Most Common Patterns:
    1. defaultdict(int) — Counting things
        # Without defaultdict
            word_counts = {}
            for word in words:
                if word not in word_counts:
                    word_counts[word] = 0
                word_counts[word] += 1

            # With defaultdict
            word_counts = defaultdict(int)
            for word in words:
                word_counts[word] += 1  # auto-creates with 0
    
    2. defaultdict(list) — Grouping things
        # Without defaultdict
        teams = {}
        for name, team in players:
            if team not in teams:
                teams[team] = []
            teams[team].append(name)

        # With defaultdict
        teams = defaultdict(list)
        for name, team in players:
            teams[team].append(name)  # auto-creates with []

    3. defaultdict(set) — Unique groupings
        # Auto-creates an empty set
        visitors = defaultdict(set)
        visitors["page1"].add("user1")  # auto-creates set()
        visitors["page1"].add("user2")

    Now Let's Tackle The Nested One
        self.balance_sheet = defaultdict(lambda: defaultdict(float))

        Break it down layer by layer:
        Outer: defaultdict(lambda: ...) — When you access a missing top-level key, it calls the lambda to create the value.
        Lambda: lambda: defaultdict(float) — Creates a new defaultdict(float).
        Inner: defaultdict(float) — When you access a missing second-level key, it auto-creates with float() = 0.0.

        # Inner level: what's the final value type?
        #   → float (like 200.0)
        #   → So I need: defaultdict(float)

        # Middle level: what's the key to reach that value?
        #   → user ID string
        #   → So I need: dict[str, defaultdict(float)]

        # Outer level: what's the key to reach the middle?
        #   → another user ID string
        #   → So I need: dict[str, dict[str, defaultdict(float)]]

        # But I want auto-creation at both levels:
        #   → defaultdict(lambda: defaultdict(float))
